Does It Pass?

Here's a new equation. It looks different from the ones we've seen — it doesn't start with "y = ..."

x + y = 1

Think of it as a test. Pick any point. Add its coordinates.

If you get 1, the point passes the test. If not, it doesn't.

(0, 1) Does it pass?
(3, 2) Does it pass?
(1, 1) Does it pass?
(1, 0) Does it pass?

Two passed, two didn't. The points that pass are on the line. The ones that don't are off it.

Let's find more.

They line up. It's a line — just like y = 2x and y = x + 1 were lines.

But this line is different. Look at which direction it goes.

Downhill

Every line we've seen so far has gone uphill — the further right, the higher up.

This one goes downhill. As x increases, y decreases.

How would a knight move along this line? Right 1 — but this time, down 1.

When the step went "right 1, up 2," the slope was 2. When it went "right 1, up 3," the slope was 3.

Now it goes "right 1, down 1." The slope is −1.

A negative slope means the line goes downhill. Each step to the right goes down, not up.

Each time x goes up by 1, y goes down by 1. That's what slope −1 looks like in the numbers.

Rewriting the Equation

Can we rewrite x + y = 1 so it looks more like y = ...?

Take any point that passes the test x + y = 1. That means its coordinates add up to 1:

x + y = 1
Take x away from both sides:
x + y − x = 1 − x
On the left, x − x is nothing. So:
y = 1 − x

So the point also passes the test y = 1 − x. Every point on the line x + y = 1 is also on the line y = 1 − x.

Now go the other way. Take any point that passes the test y = 1 − x:

y = 1 − x
Add x to both sides:
x + y = x + 1 − x
On the right, x − x is nothing. So:
x + y = 1

So the point also passes the test x + y = 1. Every point on the line y = 1 − x is also on the line x + y = 1.

Same Line

Both directions work.

Every point on one line is on the other. They are the same line.

Two equations are equivalent if they describe exactly the same set of points — the same line.

An equation with x and y is a test: plug in a point, and it either passes or fails.

The points that pass the test x + y = 1 form a line — a line with slope −1.
